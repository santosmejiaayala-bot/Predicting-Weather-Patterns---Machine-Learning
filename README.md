This project uses supervised machine learning to predict next-day mean temperatures across 18 European locations using historical weather observations. The dataset contains 3,654 daily observations collected between 2000 and 2010 and includes measurements such as temperature, humidity, pressure, and wind conditions. To improve predictive performance, the data were enhanced with lagged variables, rolling averages, interaction terms, and calendar-based features. Missing values were handled using median imputation within a Scikit-learn pipeline, and the models were evaluated using a chronological train-test split and time-series cross-validation.

A Decision Tree, Random Forest, and mean baseline model were compared using mean absolute error (MAE), mean squared error (MSE), and R² on unseen test data. The Random Forest achieved the best performance with a test MAE of 1.58°C and an R² of 0.92, substantially outperforming both the Decision Tree and baseline model. This project demonstrates feature engineering, time-series forecasting, ensemble learning, model evaluation, and data visualization using Python, Pandas, NumPy, Matplotlib, and Scikit-learn.
